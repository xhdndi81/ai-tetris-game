# 🧩 꼬마 테트리스 - 블록을 맞춰 줄 없애기

> **아이들을 위한 친절한 테트리스 게임입니다.** 브라우저에서 바로 플레이할 수 있고, 이름과 난이도를 고른 뒤 블록을 맞춰 줄을 없애며 점수를 쌓을 수 있습니다.

## 📖 프로젝트 소개

**꼬마 테트리스**는 초등학생도 쉽게 즐길 수 있는 교육용 테트리스입니다. 떨어지는 블록을 회전하고 옮겨 가로줄을 가득 채우면 줄이 사라지고 점수를 얻습니다. 게임이 끝날 때마다 기록이 저장되어 어제보다 더 잘했는지 비교할 수 있습니다.

### ✨ 주요 기능

- 🧩 **클래식 테트리스**: I, O, T, S, Z, J, L 7종류 블록과 7-bag 랜덤
- 👀 **미리보기와 보관**: 다음 블록 3개 미리보기, 홀드, 착지 위치 고스트
- 🌱 **난이도 선택**: 쉬움, 보통, 어려움, 마스터 4단계
- 👶 **아이 친화적 UI**: 초등학생도 쉽게 사용할 수 있는 따뜻한 인터페이스
- 💬 **음성 격려 멘트**: Web Speech API(TTS)로 아이의 이름을 부르며 응원
- 🏆 **자동 기록 저장**: 점수, 레벨, 줄 수를 브라우저에 저장
- 📱 **반응형 디자인**: 키보드와 화면 버튼으로 스마트폰·태블릿에서도 플레이

---

## 🛠️ 기술 스택

### Backend
- **Java 17 / Spring Boot 3.2.0**
- **Spring Web**: 정적 웹 리소스 제공
- **Spring Boot DevTools**: 로컬 개발 시 자동 새로고침

### Frontend
- **HTML5 / CSS3 / JavaScript (Vanilla JS + jQuery)**
- **Canvas Tetris Engine**: 자체 구현한 테트리스 게임 엔진
- **Web Speech API**: 시스템 TTS를 이용한 한국어 음성 출력

## 🚀 설치 및 실행 방법

### 1. 사전 요구사항
- **JDK 17 이상**, **Maven 3.9 이상**

### 2. 실행
```bash
mvn spring-boot:run
```
접속 주소: `http://localhost:8080`

데이터베이스나 API 키 없이 바로 실행됩니다.

## 🎮 조작 방법

| 동작 | 키보드 | 화면 버튼 |
| --- | --- | --- |
| 왼쪽 / 오른쪽 | ← / → | ◀ / ▶ |
| 회전 | ↑, X (시계) / Z (반시계) | ↻ |
| 천천히 내리기 | ↓ | ▼ |
| 바로 떨어뜨리기 | Space | 떨어뜨리기 |
| 보관(홀드) | C | 보관 |
| 일시정지 | P, Esc | 일시정지 |

### 난이도
- **쉬움**: 블록이 천천히 내려옵니다.
- **보통**: 기본 속도입니다.
- **어려움**: 더 빠르게 시작하고 잠금도 짧습니다.
- **마스터**: 아주 빠르게 내려옵니다.

## 🎯 테트리스 규칙

- 블록은 가로 10칸, 세로 20칸 보드에 떨어집니다.
- 가로줄이 가득 차면 그 줄이 사라지고 점수를 얻습니다.
- 한 번에 4줄을 없애면 **테트리스**로 가장 높은 점수를 받습니다.
- 줄을 없앨수록 레벨이 오르고 블록이 더 빨리 내려옵니다.
- 새 블록이 나올 자리가 없으면 게임이 끝납니다.
